How it works

Three steps. Nothing to install, nothing to sign into.

  1. 01

    Paste

    Drop any http(s) link. The same URL always returns the same code.

  2. 02

    Share

    Get a short 302 link. No ads, no interstitial page, no login wall.

  3. 03

    Count

    Every visit increments a public counter. Anyone with the code can see it in Inspect — no accounts, no dashboards.

API POST /shorten 
# Idempotency-Key makes retries safe — same key returns the same code
curl -X POST /shorten \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 6e8b0b2a" \
  -d '{"longUrl":"https://example.com/very/long/path"}'

→ 201 {"shortUrl":"…/b", "shortCode":"b"}
